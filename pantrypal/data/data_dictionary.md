# Data dictionary

## product_catalog.csv

The 40 products in the demo. `product_id` is the key in every team file.
Generated by `build_catalog.py` from `ml/out/sku_list.csv`; edit the script, not the CSV.

| Column | Meaning |
|---|---|
| `product_id` | Product ID from the FreshRetailNet-50K dataset |
| `first_category_id`, `second_category_id`, `third_category_id` | Dataset category IDs, broadest to finest |
| `name` | Display name used in alerts, e.g. "12 kg Tomatoes expire in 2 days" |
| `category` | Product group (invented; the dataset categories are anonymous) |
| `shelf_life_days` | Days from receiving a batch until it expires. Set per category |
| `unit` | Unit for quantities: `kg`, `packs`, `loaves`, `trays` or `bunches` |

## sample_pos_export.csv

One day of sales at the demo store (2024-06-20) in the format `POST /sales/import` reads.
Two rows are wrong on purpose to show the validation: an unknown product and an impossible date.
Generated by `backend/seed_demo.py --pos-export`.

| Column | Meaning |
|---|---|
| `date` | Sale date as `DD/MM/YYYY` (`YYYY-MM-DD` also works) |
| `product` | Product `name` from product_catalog.csv in any case, or its `product_id` |
| `quantity` | Amount sold, in the product's `unit` |

Files with other headers can still be imported by telling the API which column is which
(`date_column`, `product_column`, `quantity_column`: the app's Map step).
